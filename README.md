This is a very basic introduction to point set topology and algebraic topology.

People who are interested in set point topology but with no foundation at all 
can start from chapter 2,while people who have learned mathematical (real) analysis can start from chapter 1.

People who are interested in algebraic topology and have a certain foundation in group theory 
(at least one should know group homomorphism, quotient, group isomorphism and group action)
can start reading from the chapter called Quotient Space and Simplicial Complex.
